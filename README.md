## Features

- **Infinite Scroll Pagination** – Loads more users automatically as you scroll down (lazy loading on-demand)
- **Pull-to-Refresh** – Refresh the list with fresh data using the pull gesture
- **Search by Name** – Real-time client-side filtering by full name (first + last)
- **Skeleton Loading** – Beautiful shimmer placeholders while data is loading
- **Error & Empty States** – Proper handling for loading, errors, and no-search-results
- **Clean Navigation** – Detail screen for each user with smooth Hero animation on avatar
- **Efficient State Management** – Using Provider (ChangeNotifier) – no unnecessary API calls
- **Mobile-first Responsive UI** – Optimized for Android & iOS screens
- **Clean Architecture** – Separation of concerns (Models / Services / Providers / Screens)
